# Description and tags

Write the YouTube description and a list of tags.

## Description rules
- First 2 lines: what the video shows and why it is useful (these appear before "show more").
- Then 3 to 6 short bullet points of what is covered, based only on the content provided.
- Then one closing line inviting the viewer to comment with their own workflow.
- Do NOT include chapters or timestamps; they are added separately.
- Do NOT include links, prices, or claims about tools that are not in the content.
- Plain text only.

## Tags
- 8 to 15 tags, most relevant first. Short phrases. Each tag under 30 characters.

## JSON keys
```json
{
  "description": "plain text description",
  "tags": ["tag one", "tag two"]
}
```
